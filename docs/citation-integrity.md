# 出典付き引用の整合性

記事・Reader本文を更新した後も、原稿と調査メモに保存した引用の出所を確認できるよう、本文全体のハッシュと引用段落のハッシュ、引用元本文リビジョンを保持します。

- 引用段落が同じで別段落のみが改訂された場合、引用を `verified` のまま表示し、引用箇所以外の改訂を示します。
- 引用が別段落へ一意に移動した場合は `quote_moved` として旧位置を維持します。利用者が原文を確認して再結合したときに、旧レコードを残したまま後継引用を作成します。
- 引用文が消えた、重複した、本文がない、旧形式で検証できない場合は、それぞれ未確認状態として扱います。曖昧な候補へ自動で結び直しません。
- 既存の原稿、Reader本文、引用、思考メモ参照は保持します。引用メタデータとReader本文の追記履歴を追加するSQLite migrationを使います。

検証はローカルSQLiteのAPIテストで行います。ユーザーがこの表示を正しく理解するか、引用履歴がどれだけ容量を使うかは別途検証が必要です。
