# 説明の訂正と一貫した判断基準

## C1：自動化
- **誤っていた表現**：「自動化を増やすほど不利という考え方への反証」。これは既存方針を取り違えたもの。
- **正**：当初から、手作業・介入コストを減らす自動化を積極的に検討し、**やりすぎによる確認・修正・誤適用の損失と釣り合わせる**ことを目標としていた。
- **研究で言えること**：特定の提案/適応方式で時間利益と認知コストの両面が報告されている。自動化水準に対する効用の一般的単調性も、厳密な逆U字も証明されていない。
- **正しい判断**：低・中・高の比較から始め、どの課題/利用者/精度で何が勝つかを分析する。「高自動化は危険だから既定OFF」は本番安全の**暫定運用**であり、価値判断ではない。

## C2：UI
- **誤解を招いた表現**：「具体的な表示方式を文献だけで固定するのは危険」を新しい結論のように提示した。
- **正**：それこそ当初合意した「塩梅の比較」の内容であり、方針変更ではない。
- **変えない制約**：検索/Readerに常に到達できる、主要操作の位置を無断で乱さない、読書のフォーカスを奪わない、キーボードや読み上げへのアクセスを壊さない。
- **比較して決めるもの**：表示タイミング、文脈ヒントの強さ、非モーダル自動展開、ユーザー主導表示、頻度上限、戻し方。効果が確認されれば本番の既定は変更可能。

## C3：説明と出典
根拠保持はデータ完全性の要件。説明文を多く表示することは、ユーザーが実際に誤りを検出できることの証明ではない。正答/見逃し/検証時間を比較する。

## C4：過去の訂正を引き継ぐ
- Inoreaderにも記事内ノート・注釈がある。記事を見ながらメモすることだけを独自性としない。
- 検索E5/RRFの匿名化プレースホルダー評価を独立な実利用カードの品質証拠にしない。旧50問はホールドアウトではない。
- 2026年11月4日のローカルReader実装報告は、現在のローカルツリーで検証するまでは「過去の報告」。
- 2024年AI協働メタ分析の平均的な相乗効果不足を「自動化一般が無益」と読み替えない。AI単独と人間単独のベースラインが異なる。

## C5：意思決定が変わる条件
「研究が新たに見つかった」だけでは変更しない。結論が変わるのは、(a) 対象タスクに近い強い独立証拠、(b) 実際のmy-searchで事前登録した有効性/安全性条件、(c) 重大な安全・互換性問題、のいずれかが判断の前提を崩した場合。`03_DECISION_REGISTER.csv`に修正履歴を残す。
