# 実験計画 E0–E9：研究の対象条件を壊さない比較

## 横断原則
- E0観察で対象業務の負担を把握し、E6で統合の効用を先に検証する。AIの機能数を増やすことを目的にしない。
- 課題そのもの、バックエンド、提案品質、表示形式、頻度、ツールの権限を**同時に変えない**。不能なら交絡と明示し、因果効果と呼ばない。
- 主要指標は、正しい成果物に到達したか、総経過時間、初回に必要な手続きと後の管理負担。補助指標は確認・誤誘導・修正・再開・発見可能性・信頼の校正。
- 参加者内試験では複数の難易度を検証した課題バンクを使い、被験者×条件×課題×順序を釣り合わせる。同じ課題を繰り返して先に答えを覚えさせない。
- 本試験前の予備試験でタスク理解、計測ログの完全性、難易度の偏り、プライバシー同意を確認する。
- 事前登録を行い、主指標、最小重要差、非劣性許容幅、除外、停止条件、解析計画を結果を見る前に固定する。

## E0：実利用者の負担マッピング
問い：探す/読む/引用/比較/保存/再発見/中断回復のどこが実際に負担か。
条件：現行アプリ/普段の方法、持込課題と標準課題。観察と短期日誌を組み合わせる。
記録：独立した作業区分ごとの経過時間、誤り修正、断念、主観的負担、設定費用。発話/本文はデフォルト非保存。
判定：次に優先する機能を選ぶための探索研究。**因果的な改善証拠ではない**。

## E1：UI表示の塩梅（V軸）
条件：現行V0 / 控えめなヒントV1 / 非モーダル自動展開V2 / 任意常設表示V3（必要時）。AとTの振る舞い、記事、提案内容を固定。
主要：正確性、時間、初見発見率。副：機能再発見率、視覚妨害、スクリーンリーダー/キーボード到達、複数回利用後の成績。
反証：自動提示で初回発見だけ上がるが慣れた後に遅くなる、あるいは固定で未知機能が見つからない場合。

## E2：介入タイミング（T軸）
条件：T1明示要求 / T2作業区切りでの提示 / T3即時提示。**全条件で同じ提案を生成できる**ように保持し、表示内容・量・権限を固定。T0オフは「提案の有無」の**別の比較**として測る。
主要：総時間・成果精度・割込み後の復帰時間。副：提案提示遅延・不要提示・無視率・確認時間・誤介入修正。
注意：オフvs即時はタイミングだけでなく提案有無の差を含む。区切り検出の精度/見逃しを記録。

## E3：作業文脈の推定と再開
条件：最終セッション復元 / ルール型の活動区切り提案 / モデル推定による区切り提案。試験では推定結果を**勝手に保存カードへ結合しない**。
主要：ユーザーが事後確認した正解区切りに対する誤結合・誤分割・訂正時間、情報消失、再開成功率。
必要データ：同意済み匿名化操作シーケンス、事後検証ラベル、活動が交差するケース。

## E4：AIの生成・道具化と自動化権限（A軸）
2つの因子を混同しない：内容生成（記事のみ/AI文章/型付き道具）と実行権限（明示起動/確認付き/可逆な自動実行）。**どちらか一方を固定して順に調べる**。
主要：単位・数値・入力範囲・計算結果・拒否/訂正が正確か、正確な成果物までの時間、検証時間、対象記事の適用率。
安全：本物のユーザーデータに対するA3完全自動の破壊的実行は実験にも含めない。高自動化は隔離データと可逆操作でのみ評価。

## E5：整理/検索/再発見
第1段：手作業で正解づけした未知の自然なクエリで現行BM25と候補方式をランキング（Hit@k/nDCG@k/Latency/Memory）比較。
第2段：任意タグのみ / 提案付き任意整理 / 自動整理の**非破壊シミュレーション**で再発見、整理と訂正のコスト比較。
注意：過去に調整に使った50問、匿名化テキスト代理を新しい独立正解と呼ばない。

## E6：実際の統合効果（優先）
比較A 旧MVP、B 同じ機能を分離した状態、C 同じ機能を統合した状態。**BとCの機能・品質・記事コーパスは同じで、連結方式だけ異なる**。
主：正確な最終成果、総時間、管理/修復時間。副：中断再開、再発見、操作負担、1回目と慣れた後の違い。
A対Cは全体の開発改善を、B対Cは統合自体の効果を問う。差を混同しない。

## E7：適応・自動化の長期負担
対象：E1/E2/E4で有望だった条件。数日～数週間使った後の時間、利用率、不要提示、設定・修正、離脱を測る。初見実験の勝者を無条件に本番化しない。

## E8：作業再開の補助
条件：状態/履歴だけ / 本人メモあり / AI要約あり / 履歴＋AI要約（必要なら）。主：再開後の**最終的な成功率**と総時間。副：再開に要した時間、要約誤り、本文・出典照合回数。
注意：AI要約で復帰が速いことと、終わりまで正しく完遂することは別。AI要約によって履歴や原本を消さない。

## E9：AIの説明・出典・検証可能性
条件：結果のみ / 説明テキスト付き / 元記事箇所や計算式に遡れる（必要なら組合せ）。同じ誤り分布の回答を提示し、どこで誤りに気付くかを測る。
主：正誤検出、最終正答、検証＋修正の時間。副：過信/過小信、根拠への移動、入力の検証可能性。
注意：出典保存は基盤要件。**説明の表示が多い方が良いと先に決めない**。AI単独で完遂できる課題ならAI単独も対照に入れる。

## 横断失敗時の戻り方
E1/E2/E3/E4の効果が弱い/正確性を下げる→機能は手動・任意で残し、既定を変更しない。E6の統合が不利→連携点と管理コストを再設計。E5で候補ランキングが不安定→BM25維持。安全ゲート失敗→実験終了しデータ復旧。
