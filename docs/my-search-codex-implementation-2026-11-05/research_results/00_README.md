# my-search 関連研究・研究結果そのまま提示版

**作成日：2026-11-05**

このパッケージは、過去に調べた研究を、**元研究の対象・方法・比較条件・報告結果・限界・リンク**として提示するものです。

**含めていないもの**：my-searchの理想像、設計推奨、導入優先度、Codex実装指示、採否判断、AI側の賛否や一般化。

## ファイル構成

1. `01_PRIMARY_SOURCE_CHECKED_RESULTS.md`：今回、原典や学会・研究機関の公式要旨と再照合した**10件**の研究・概念枠組み。方法と結果を研究別に提示。
2. `02_PAST_STUDIES_AS_RECORDED.md`：過去の研究台帳にある**48件**の研究・レビュー・実証評価・ベンチマーク。過去の記録をそのまま整理。全件再検証ではない。
3. `03_STUDY_FACTS.jsonl`：2の48件を**実験結果／限界／URL**等に分割した機械可読形式。原テキストと出典の区別を保持。
4. `04_STANDARDS_AND_GUIDELINES.md`：研究と混同しないため、過去台帳の**4規格と1報告ガイド**を別掲載。
5. `05_SOURCE_CHECK_AND_VERSION_NOTES.md`：原典照合の範囲と論文の改訂版差分。
6. `SHA256SUMS.txt`：収録ファイルのハッシュ。

旧台帳に含まれていた「my-searchへの含意」「設計への影響」などの判断列は取り込んでいません。

## 重要な区別

- `01`＝今回、一次情報に再照合した要約。
- `02`＝過去に記録した研究結果を、当時のまま整理して抜粋したもの。**未照合の箇所を確証に変換していない**。
- `04`＝規格・ガイドであり、実験結果ではない。
- 日本語は原典の全文翻訳ではなく、原典結果を日本語で短く再記述したもの。転載許諾を得た本文全文の複製ではない。

研究論文の数を増やすために、新しい論文や数値を補っていません。
