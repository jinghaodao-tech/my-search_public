# my-search Codex実装指示（2026-11-05）

## 使い方
1. ZIPを展開して、リポジトリから参照できる場所に置く。
2. Codexに `01_CODEX_EXECUTE.md` の実行を依頼する。追加質問を待たずにローカルコードの棚卸し、実装、テスト、報告まで行う。
3. 添付した `research_results/` は研究結果の記録。`decision_context/` は別種の意思決定資料。研究結果を設計指示として誤読しない。

## 主眼
- **安定基盤**: 検索→Reader→引用/メモ→既存道具→保存→復元。既存実装の再利用と非破壊の連携。
- **実験基盤**: 自動化(A)、UI表示(V)、介入タイミング(T)を独立制御。フラグOFFが通常動作。
- **証拠づくり**: まずE0（負担マッピング）とE6（統合の効果）の比較ができるところまで実装。
- **禁止**: 現行ランキングの変更、強制分類、任意生成コード実行、同意なきログ収集、実利用者効果の捏造。

このパッケージは**実装指示と研究資料**であり、my-search本体を改修した成果物ではない。実装と実験はCodexがローカルで行い、報告すること。
