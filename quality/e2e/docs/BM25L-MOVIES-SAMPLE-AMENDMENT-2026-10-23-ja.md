# BM25L Moviesサンプル実行の事前変更

Books結果を確認した後、Movies全7,086 target groupのBM25L比較を起動したが、最初の400 groupを処理した時点で、全件実行に長い時間を要することが判明した。指標・候補スコアはまだ出力されていない状態でプロセスを停止した。

Moviesの結果を見る前に、既存の固定SHA-256順から先頭1,500 target groupを使うよう計画を変更する。クエリ選択はラベル・順位・スコアを参照しない。これは探索的な計算量削減であり、未使用holdoutを作る変更ではない。`group-limit=1500` の固定選択を用い、結果を見た後に標本数や指標を変更しない。
