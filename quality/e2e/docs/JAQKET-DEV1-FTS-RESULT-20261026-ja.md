# JAQKET dev1 FTS5探索結果

2026-10-26。日本語の公開クイズQAを使った探索・転移評価であり、保存記事再発見の一般性能や最終95%達成を示すものではない。

## 条件

- split: 公開 `dev1` 995問から、JQaRAで既使用の正解記事グループ137問を除外した858問・850正解記事グループ。
- コーパス: JAQKET候補Wikipedia 114,228文書。形態素FTS5索引のSQLite整合性は `ok`、正解記事1,950件は全件収録。
- 検索: アプリのクエリ解析と形態素解析、FTS5-BM25、候補深度100。
- 品質: Hit@10、正解記事グループ単位bootstrap 10,000回。
- 時間: 検索文の解析開始から上位候補取得まで。索引作成時間は除外。各問は逐次処理し、キャッシュは使用しない。
- 実行: `npx tsx scripts/bench/benchmark_jaqket_retrieval.ts dev1 quality/e2e/local/jaqket-public quality/e2e/local/jaqket-public/corpus.sqlite quality/e2e/local/jaqket-public/result-dev1-fts-20261026-v1.json 100 fts-only`

## 結果

| 指標 | 結果 |
|---|---:|
| Hit@10 | 643/858 (74.94%) |
| 95%対象記事グループbootstrap区間 | 72.01–77.89% |
| Top100候補coverage | 747/858 (87.06%) |
| 候補取得後にTop10へ入らなかった質問 | 104/747 |
| 候補未発見 | 111/858 |
| API・索引エラー | 0 |
| API相当検索時間 p50 / p95 | 1,142.6 / 1,942.2 ms |
| クエリ解析 p95 | 2.31 ms |
| FTS5候補取得 p95 | 1,939.7 ms |
| 全858問の逐次処理時間 | 1,023.3秒 |

本目標のHit@10 95%と比べると大きく下回る。失敗215問のうち111問はTop100候補に正解記事がなく、104問は候補にある正解をTop10へ順位付けできなかった。したがって再順位だけでは候補取得の失敗を解決できず、候補拡張・検索語の解析・索引規模への対応が必要である。

このコーパスは目標の検索対象（1万〜3万件）を上回る114,228件なので、約1.94秒のp95を性能目標の合否に流用しない。10k件で既に測定した500ms以下の結果とも別測定として扱う。公開devは方式探索に使ったため今後の最終評価には使わない。

ローカルの集計JSONはGit除外ディレクトリ `quality/e2e/local/jaqket-public/result-dev1-fts-20261026-v1.json` に保存した。質問文・正解タイトルは結果ファイルへ含めず、質問・コーパス・設定・実装指紋を記録している。
