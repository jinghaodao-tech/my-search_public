# Movies生テキストFTS5単独順位・固定群確認計画

## 目的・位置づけ

過去のMovies開発標本での信号別探索および1つの群分離確認では、生テキストFTS5単独順位が標準BM25に対してMRR@10の正方向を示した。これを新しい対象群で一度確認する。方式選択後の開発分割内確認であり、独立コーパス・最終ホールドアウト・実利用データの認定ではない。

## 固定条件

- データ: Reddit-TOMT Movies development、全8,845文書、隔離SQLiteはread-only。
- 標本: `SHA-256(group_id)` 昇順offset 4002から500群。各群から `SHA-256(group_id + NUL + query_id)` 昇順の先頭クエリを1件選ぶ。
- 主方式: `cards_fts` の既存生テキストFTS5 BM25順位（title/body/summary/tags、標準列重み、単独ランキング）。
- 基準: 独立標準形態素BM25 k1=1.2,b=0.75。共有解析語、同じ8,845文書、同じqrel。
- 主指標: MRR@10。補助: Hit@10、Hit@1、nDCG@10。正解対象群単位の対応bootstrap 95%区間を出す。
- MRR@10差の区間下限が0を超えた場合のみ、このMovies開発サンプルで改善方向を確認できたと記述する。Hit@10優位性は別判定。
- 他の方式も診断値として出力するが、この標本を見て採用方式を選び直したり、主指標を変更したりしない。
