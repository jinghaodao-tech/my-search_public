# Movies形態素FTS5単独方式・固定群確認計画

## 目的・位置づけ

既使用Movies開発群の信号アブレーションでは、形態素FTS5単独が標準形態素BM25に対してHit@10を改善し、N-gram追加は低下と関連した。ここではより単純な形態素FTS5単独方式を一つ固定し、新しい対象群で方向を確認する。開発分割内の群分離確認であり、外部独立コーパスや最終ホールドアウト認定ではない。

## 固定条件

- データ: Reddit-TOMT Movies development、8,845文書、既存隔離SQLiteをread-onlyで使用。
- 標本: `SHA-256(group_id)` 順offset 3502から500群、各群1クエリを `SHA-256(group_id + NUL + query_id)` 順で選択する。
- 主比較: SQLite FTS5形態素トークン単独のネイティブBM25順位 vs 独立標準BM25 (k1=1.2,b=0.75)。両者は同じ保存済み形態素トークン文書集合・共有クエリ解析語・qrelを使用する。
- FTS5 N-gram/raw/RRFは比較用に出力するが、主要方式選択・係数調整にはこの群を使わない。
- 主指標Hit@10、補助Hit@1/MRR@10/nDCG@10。群単位対応bootstrap 95%区間を保存する。
- qrel、クエリ、ランキングを使った群選択はしない。結果後に方式を変更して同じ群を再認定しない。
