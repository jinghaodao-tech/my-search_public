# TC01〜TC10の評価

依頼対象は前回の10ケース。評価キットに同梱された合成18例TC11〜TC28は対象外とした。キットからrubric/criteria.json、scripts/common.mjs、scripts/summarize.mjsだけを取り出し、元の分析結果のコピーをcases/に保存した。原本は変更していない。既存採点票・集計・回答キーは参照していない。

同梱スクリプトはcases/内のIDを列挙する設計なので、変更せず10ケースへ適用できる。

評価者same-session-reviewは分析時の会話履歴を持つ。同一セッションによる事後レビューであり、独立・盲検評価ではない。採点は評価者の判断であり、精度・検出率・実業務での有効性の証明ではない。

実行日: 2026-10-12。grade.mjsは記録した判定・引用を採点票へ出力する補助スクリプトで、意味を自動採点する評価器ではない。

通常項目C09の問題: TC03、TC08、TC09で要求を全目的へ一律に関連付けるため、寄与関係と制約・対立関係が混在する。重大項目の失敗は認定していない。単一の検証計画V1に全主張を集約する点も詳細化の余地がある。

採点票の形式・ハッシュ検査と集計は `node scripts/summarize.mjs same-session-review` で実行する。独立評価が必要な場合は、分析履歴を持たない別評価者へ原文・レポート・ルーブリックのみを渡す。
